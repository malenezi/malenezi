#### Description

This training program is designed to enable participants to understand and build modern, scalable, secure, and production-ready data architectures that support Artificial Intelligence systems and intelligent analytics platforms. The program focuses on the evolution of modern data engineering, the shift from data warehouses and data lakes to Lakehouse architectures, and the use of Delta Lake, ACID transactions, compute-storage decoupling, real-time streaming pipelines, data quality, observability, and governance. It also includes a hands-on lab for building a local Mini-Lakehouse using Delta Lake.

- Understand ACID transactions and their importance in protecting data from corruption and operational errors.
- Implement a hands-on Mini-Lakehouse using Delta Lake and PySpark.
- Connect modern data architecture components to AI, reporting, and analytics requirements.

#### Curriculum / Modules

**1. Introduction to the Modern Data Engineering Ecosystem**

- Understand the role of data engineering in enabling AI systems, where intelligent models depend on reliable, structured, and usable data.
- Learn how data moves through collection, cleansing, transformation, validation, and delivery stages before reaching analytical systems and AI models.
- Review the core components of the modern data engineering ecosystem, including storage, compute, integration, quality, and governance.

**2. The Evolution of Data Architectures from Warehouses to Lakehouse**

- Explain the evolution of data architectures from traditional data warehouses to data lakes and then to the modern Lakehouse architecture.
- Clarify the advantages and limitations of each architecture in terms of data types, cost, scalability, reliability, analytics, and AI support.
- Connect the Lakehouse architecture to the need for a unified and trusted data source that supports reporting, data science, and generative AI models.

**3. Compute-Storage Decoupling**

- Understand compute-storage decoupling as a core architectural principle in modern cloud data environments.
- Explain how data can be stored in an independent low-cost storage layer while compute resources are activated only when processing is needed.
- Demonstrate how this principle reduces cost, increases flexibility, improves scalability, and minimizes points of failure in technical infrastructure.

**4. Data Integration and the Shift from ETL to ELT**

- Understand how data is moved from different sources into storage and analytical platforms using ETL and ELT approaches.
- Differentiate between ETL, which transforms data before loading, and ELT, which loads data first and then transforms it inside the storage or analytics environment.
- Explain the role of ELT in preserving raw data, improving ingestion speed, increasing analytical flexibility, and simplifying recovery from transformation errors.

**5. Real-Time Streaming Systems and Event-Driven Architectures**

- Differentiate between traditional batch processing and real-time streaming, where data is processed as soon as it is generated.
- Explain the components of event-driven data pipelines, including producers, message brokers, and consumers.
- Clarify real-time streaming use cases in AI systems, such as fraud detection, location tracking, and real-time decision updates.

**6. Data Quality, Observability, and Governance**

- Understand the role of data governance in defining ownership, access rights, policies, and secure handling mechanisms for organizational data.
- Recognize data quality as a set of controls and tests that ensure data accuracy, completeness, and consistency before it is used in reports or models.
- Explain data observability and lineage tracking as mechanisms for detecting failures, identifying root causes, and resolving data pipeline issues quickly.

**7. Data Warehouses, Data Lakes, and Lakehouse Architecture**

- Compare data warehouses, data lakes, and Lakehouse architecture in terms of supported data types, processing patterns, cost, and reliability.
- Understand the role of data warehouses in structured reporting and analytics, and the role of data lakes in storing raw and diverse data.
- Explain how Lakehouse architecture combines the flexibility of data lakes with the reliability of data warehouses through advanced management and governance layers.

**8. Delta Lake and ACID Transactions**

- Understand Delta Lake as an open-source storage layer that adds reliability and structure to data lakes.
- Explain ACID transactions through the principles of atomicity, consistency, isolation, and durability, and their role in protecting data during write and update operations.
- Demonstrate how Delta Lake provides transaction logs, schema enforcement, and time travel capabilities to improve auditing and data recovery.

**9. Hands-on Lab: Building a Mini-Lakehouse Using Delta Lake**

- Build a local practical environment using PySpark and Delta Lake to simulate a modern Lakehouse environment.
- Apply key capabilities such as ACID transactions, schema enforcement, version tracking, and time travel.
- Analyze lab outputs to understand how Delta Lake prevents data corruption, tracks operations, and supports auditability and reproducibility in AI environments.

- توضيح أثر هذا المبدأ في خفض التكلفة، وزيادة المرونة، وتحسين قابلية التوسع، وتقليل نقاط الفشل في البنية التقنية.

- التمييز بين ETL الذي يحول البيانات قبل تحميلها، وELT الذي يحمل البيانات أولًا ثم يحولها داخل بيئة التخزين أو التحليل.
- شرح دور ELT في حفظ البيانات الخام، وتحسين سرعة الاستيعاب، وزيادة مرونة التحليل، وتسهيل التعافي من أخطاء التحويل.

- توضيح استخدامات التدفق اللحظي في أنظمة الذكاء الاصطناعي، مثل كشف الاحتيال، وتتبع المواقع، وتحديث القرارات في الوقت الحقيقي.

- شرح مفهوم مراقبة البيانات وتتبع نسبها ومسارها لاكتشاف الأعطال، وتحديد أسباب الأخطاء، ومعالجتها بسرعة في خطوط البيانات.

**7. مستودعات البيانات وبحيرات البيانات ومعمارية Lakehouse**

- المقارنة بين مستودعات البيانات، وبحيرات البيانات، ومعمارية Lakehouse من حيث أنواع البيانات المدعومة، ونمط المعالجة، والتكلفة، والموثوقية.

**8. Delta Lake ومعاملات ACID**

#### Curriculum / Modules

**1. Data Modeling Fundamentals**

- Understand the concept of data modeling and its role in translating business requirements into clear and structured data designs.
- Differentiate between conceptual, logical, and physical data models and understand when each model is used.
- Explain the relationship between data modeling, data quality, system integration, reporting, and analytics.

**2. Business Requirements Analysis for Data Modeling**

- Learn how to gather business requirements from stakeholders and convert them into entities, attributes, and relationships.
- Analyze and document business rules in a way that supports accurate and implementable data models.
- Apply practical examples to transform business processes into initial data models.

**3. Entity and Relationship Design**

- Identify main entities, supporting entities, and their related attributes within a data model.
- Explain relationship types, including one-to-one, one-to-many, and many-to-many relationships.
- Apply design rules for relationships, primary keys, and foreign keys to ensure consistency and reduce redundancy.

**4. Normalization and Design Quality Improvement**

- Understand normalization and its role in reducing redundancy and improving data consistency in relational databases.
- Recognize the main normalization forms and apply them when designing tables and relationships.
- Balance normalization with performance and practical reporting and analytics requirements.

**5. Physical Modeling and Database Design**

- Convert the logical data model into a physical design that can be implemented in a database.
- Define tables, data types, keys, indexes, and constraints that support data integrity.
- Discuss performance, scalability, and maintainability considerations when implementing data models.

**6. Data Warehouse Design**

- Understand the concept of a data warehouse and its role in integrating data from multiple sources for analysis and decision-making.
- Explain the difference between operational databases and data warehouses in terms of purpose, structure, and usage.
- Review data warehouse components, including data sources, extraction, transformation, loading, and the analytical presentation layer.

**7. Dimensional Modeling**

- Understand dimensional modeling and its role in creating user-friendly models for analysis and reporting.
- Explain fact tables and dimension tables, and how to design analytical measures and metrics.
- Apply star schema and snowflake schema designs and select the most suitable structure based on data and business needs.

**8. Data Integration and ETL/ELT Processes**

- Understand the stages of extracting, transforming, and loading data from different systems into a data warehouse.
- Differentiate between ETL and ELT approaches and identify appropriate use cases for each.
- Discuss data quality controls during integration, including validation, cleansing, matching, and error tracking.

**9. Business Intelligence and Dashboards**

- Understand business intelligence and its role in turning data into reports and dashboards that support decision-making.
- Define key performance indicators and connect them to appropriate data sources and analytical models.
- Design visualizations and dashboards that support clarity, readability, and end-user needs.

**10. Data Model Documentation and Definition Governance**

- Document entities, attributes, relationships, and business rules in a way that supports understanding and maintenance.
- Prepare a data dictionary that defines each data element, its source, and its usage.
- Link documentation to data governance to standardize terminology and improve data quality and analytical use.

**11. Applied Project in Data Modeling and Business Intelligence**

- Implement a practical project that starts with requirements analysis and ends with a usable data model.
- Build a data warehouse model or dimensional model that supports defined metrics and analytical needs.
- Present the results through a dashboard or analytical report and explain the design decisions made.

#### Curriculum / Modules

**1. Introduction to Computer Vision and Practical Applications**

- Understand computer vision and its role in enabling intelligent systems to interpret and analyze images and videos.
- Review key computer vision applications across sectors such as security, manufacturing, transportation, healthcare, and retail.
- Understand the stages of building computer vision solutions, from data preparation and model training to evaluation and deployment.

**2. Image Processing Fundamentals Using OpenCV**

- Introduce OpenCV and its role in image and video processing for computer vision applications.
- Apply basic image operations such as reading, displaying, resizing, color conversion, cropping, and rotation.
- Implement image processing techniques such as smoothing, edge detection, thresholding, and contrast enhancement to extract useful visual information.

**3. Data Preparation for Computer Vision Projects**

- Understand the importance of data quality in improving computer vision model performance and output accuracy.
- Prepare datasets by organizing images, splitting them into training, validation, and testing sets, and configuring data formats.
- Learn annotation approaches for classification, bounding boxes, segmentation masks, and pose keypoints.

**4. Introduction to the Ultralytics Framework**

- Understand the Ultralytics framework and its role in simplifying the development, training, and deployment of computer vision models.
- Learn the Ultralytics workflow, including data preparation, model selection, training, evaluation, and prediction.
- Run a pre-trained model and analyze its outputs on images and videos.

**5. Image Classification Using Ultralytics**

- Understand image classification and its role in assigning images to predefined categories based on visual content.
- Train an image classification model using Ultralytics while configuring essential training settings.
- Evaluate classification model performance using suitable metrics such as accuracy, confusion matrix, and error analysis.

**6. Object Detection Using Ultralytics Models**

- Understand object detection and its role in locating objects within images and videos.
- Train an object detection model using bounding-box annotated data and configure training and validation settings.
- Analyze detection results and interpret metrics such as Precision, Recall, and mAP to improve model quality.

**7. Oriented Object Detection Using OBB**

- Understand Oriented Bounding Boxes and their importance when detecting rotated or direction-sensitive objects.
- Prepare OBB datasets and train a model capable of detecting objects with accurate angles and orientations.
- Apply oriented object detection in practical scenarios such as aerial imagery, document analysis, and industrial inspection.

**8. Image Segmentation**

- Understand image segmentation and its role in identifying object boundaries at the pixel level.
- Train a segmentation model using Ultralytics and analyze the generated masks for objects within images.
- Apply segmentation techniques in use cases such as visual isolation, scene analysis, quality inspection, and medical applications.

**9. Pose Estimation**

- Understand pose estimation and its role in identifying keypoints of people or objects in images and videos.
- Train or run a pose estimation model to extract skeletal keypoints and analyze motion or posture.
- Apply pose estimation in scenarios such as motion analysis, sports, safety, and human-machine interaction.

**10. Object Tracking in Video**

- Understand multi-object tracking and its role in linking detected objects across consecutive video frames.
- Build an object tracking system using detection models and suitable tracking algorithms to analyze movement in videos.
- Apply tracking in real-world scenarios such as movement monitoring, object counting, path analysis, and crowd management.

**11. Model Optimization and Fine-Tuning**

- Understand the factors that affect computer vision model performance, including data quality, model size, and training settings.
- Improve model accuracy through hyperparameter tuning, data augmentation, and prediction error analysis.
- Balance accuracy with inference speed and resource consumption to prepare models for practical deployment.

**12. Model Evaluation and Result Analysis**

- Learn evaluation metrics for classification, object detection, segmentation, and object tracking models.
- Read performance reports and analyze model strengths and weaknesses before deployment.
- Use evaluation results to decide whether to improve the model, retrain the data, or adjust configurations.

**13. Deploying Computer Vision Models**

- Understand export and deployment options for Ultralytics models in production environments.
- Learn deployment requirements across different environments such as servers, edge devices, smart cameras, and cloud applications.
- Apply practical steps to convert a trained model into a usable solution within a real system or application.

**14. Real-World Computer Vision Applications**

- Study real-world use cases in object detection, video analytics, quality inspection, and automated classification.
- Design a practical solution to address a defined problem using OpenCV and Ultralytics.
- Analyze practical constraints such as lighting quality, data variation, speed, accuracy, and deployment requirements.

**15. Final Applied Project**

- Complete an end-to-end project that starts with data preparation and ends with a computer vision model ready for evaluation and deployment.
- Select a practical task such as classification, object detection, segmentation, pose estimation, or object tracking.
- Present final results, analyze performance, and explain the proposed development, optimization, and deployment steps.

- التعرف على أساليب الوسم والتعليقات التوضيحية للبيانات، بما يشمل التصنيف، ومربعات الإحاطة، والتقسيم، ونقاط الوضعية.

**4. مدخل إلى إطار Ultralytics**

- التعرف على إطار Ultralytics ودوره في تبسيط تطوير وتدريب ونشر نماذج رؤية الحاسب.
- فهم بنية العمل داخل Ultralytics، بما يشمل إعداد البيانات، واختيار النموذج، والتدريب، والتقييم، والتنبؤ.
- تنفيذ تجربة أولية لتشغيل نموذج جاهز وتحليل مخرجاته على الصور والفيديو.

**5. تصنيف الصور باستخدام Ultralytics**

- فهم مفهوم تصنيف الصور ودوره في إسناد الصور إلى فئات محددة اعتمادًا على محتواها البصري.
- تدريب نموذج تصنيف صور باستخدام Ultralytics مع ضبط إعدادات التدريب الأساسية.
- تقييم أداء نموذج التصنيف باستخدام مؤشرات مناسبة، مثل الدقة، ومصفوفة الالتباس، وتحليل الأخطاء.

**6. كشف الكائنات باستخدام نماذج Ultralytics**

- التعرف على مفهوم كشف الكائنات ودوره في تحديد مواقع العناصر داخل الصور والفيديو.
- تدريب نموذج كشف كائنات باستخدام بيانات موسومة بمربعات إحاطة، وضبط إعدادات التدريب والتحقق.
- تحليل نتائج الكشف وتفسير مؤشرات الأداء مثل Precision وRecall وmAP لتحسين جودة النموذج.

**7. كشف الكائنات الموجّهة OBB**

- فهم مفهوم الكائنات الموجّهة Oriented Bounding Boxes وأهميتها عند التعامل مع الأجسام المائلة أو ذات الاتجاهات المختلفة.
- تجهيز بيانات OBB وتدريب نموذج قادر على اكتشاف الكائنات بزوايا واتجاهات دقيقة.
- تطبيق كشف الكائنات الموجّهة في سيناريوهات عملية مثل الصور الجوية، والمستندات، والمراقبة الصناعية.

**8. تقسيم الصور Segmentation**

- التعرف على مفهوم تقسيم الصور ودوره في تحديد حدود الكائنات بدقة على مستوى البكسل.
- تدريب نموذج Segmentation باستخدام Ultralytics وتحليل الأقنعة الناتجة لكل كائن داخل الصورة.
- تطبيق تقنيات التقسيم في حالات عملية مثل العزل البصري، وتحليل المشاهد، وفحص الجودة، والتطبيقات الطبية.

**9. تقدير الوضعية Pose Estimation**

- فهم مفهوم تقدير الوضعية ودوره في تحديد النقاط الرئيسية للأجسام أو الأشخاص داخل الصور والفيديو.
- تدريب أو تشغيل نموذج Pose Estimation لاستخراج النقاط الهيكلية وتحليل الحركة أو الوضعية.
- تطبيق تقدير الوضعية في سيناريوهات مثل تحليل الحركة، والرياضة، والسلامة، والتفاعل بين الإنسان والآلة.

**10. تتبع الكائنات في الفيديو**

- التعرف على مفهوم تتبع الكائنات متعددة الأهداف ودوره في ربط الكائنات عبر إطارات الفيديو المتتابعة.
- بناء نظام تتبع كائنات باستخدام نماذج الكشف وخوارزميات التتبع المناسبة لتحليل الحركة في الفيديو.
- تطبيق التتبع في سيناريوهات واقعية مثل مراقبة الحركة، وعدّ الكائنات، وتحليل المسارات، وإدارة الحشود.

**11. تحسين أداء النماذج وضبطها**

- فهم العوامل المؤثرة في أداء نماذج رؤية الحاسب، مثل جودة البيانات، وحجم النموذج، وإعدادات التدريب.
- تحسين دقة النموذج من خلال ضبط المعاملات، وزيادة البيانات، ومراجعة أخطاء التنبؤ.
- موازنة الدقة مع سرعة الاستدلال واستهلاك الموارد لضمان جاهزية النموذج للتطبيقات العملية.

**12. تقييم النماذج وتحليل النتائج**

- التعرف على مؤشرات تقييم نماذج التصنيف والكشف والتقسيم وتتبع الكائنات.
- قراءة تقارير الأداء وتحليل نقاط القوة والضعف في النموذج قبل النشر.
- استخدام نتائج التقييم لاتخاذ قرارات تحسين النموذج أو إعادة تدريب البيانات أو تعديل الإعدادات.

**13. نشر نماذج رؤية الحاسب**

- التعرف على خيارات تصدير ونشر نماذج Ultralytics لاستخدامها في التطبيقات الفعلية.
- فهم متطلبات نشر النماذج على بيئات مختلفة، مثل الخوادم، والحافة، والكاميرات الذكية، والتطبيقات السحابية.
- تطبيق خطوات عملية لتحويل النموذج المدرب إلى حل قابل للاستخدام ضمن نظام أو تطبيق حقيقي.

**14. تطبيقات عملية في العالم الحقيقي**

#### Description

A workshop aimed at empowering participants to write effective, reusable prompts and produce clear, high-quality outputs using generative AI tools. The workshop focuses on practical application through designing prompt templates, building a practical playbook, and validating output quality before sharing, with consideration for bilingual work (Arabic/English).

#### Curriculum / Modules

**1. Introduction to Prompt Engineering and Structured Prompt Writing Methodology**

- Mastering the core pillars of generative AI and learning professional frameworks for crafting precise and effective prompts.

**2. Design Prompts that Produce Consistent, Repeatable, High-Quality Outputs**

- Techniques for input optimization to minimize randomness and ensure standardized, professional results across every iteration.

**3. Build Reusable Command Templates**

- Developing dynamic prompt structures that save time and allow for seamless customization based on diverse business needs.

**4. Practical Application: Set Up a Library of Initial Prompts**

- A hands-on workshop to organize and categorize effective prompts into a structured, easily accessible database.

**5. Build a Practical Prompt Library (Playbook)**

- Creating a comprehensive strategic guide that aligns prompts with operational workflows to maximize organizational productivity.

**6. Detect Hallucinations in AI Outputs**

- Acquiring critical analysis skills to identify misinformation or inaccuracies generated by Large Language Models (LLMs).

**7. Techniques for Verifying Outputs Before Sharing Them**

- Applying rigorous auditing protocols and quality standards to ensure the reliability and professional alignment of results before final deployment.

**8. Final Practical Capstone Project**

- A comprehensive challenge designed to integrate all acquired skills and tools to solve real-world workplace scenarios
