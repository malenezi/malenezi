Nothing on Drive was modified or deleted.

    Headline findings¶

    1. The catalog is well defined; the materials are not. All 37 courses have authoritative catalog data (Module Catalog v2 or the AthkaX workbooks), but only 30 have a materials folder, and only a handful have slides, labs, datasets and assessments.
    2. Instructor packages are AI-assisted drafts. The 26 instructor packages share the structure defined in _agent_build/AGENT_INSTRUCTIONS.md, which instructs an AI agent to copy catalog facts and author the pedagogical content (labs, code, quizzes). They are strong starting points but must be technically reviewed before approval.
    3. One package is missing, two are incomplete. The file named INSTRUCTOR_PACKAGE.md for SDA-AIE-214 is actually the Addendum v1.0, which itself says the full package is authoritative — the full package is not on Drive. SDA-DSC-211 and SDA-DSC-112 packages stop after the modules (no capstone, assessment package or instructor-guide sections).
    4. Titles disagree across documents for 21 courses (§6). The Hub uses Module Catalog v2 as the single source; the other names are recorded as aliases so searches still find them.
    5. No credentials or secrets were found. Six dataset files contain Saudi-format phone / national-ID / e-mail patterns; all come from packs documented as synthetic and are flagged for confirmation (§8).

    • Third-party material.
