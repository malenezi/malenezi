# Runtime dependencies for the Rafeeq service image (deployment/, Dockerfile).
#
# SPEC §1's Layer A / Layer B split applies here exactly as it does to the
# source tree: everything below `pydantic` is Layer A (already usable in
# the training-build sandbox); everything from `langgraph` down is Layer B
# — NOT installable in that sandbox, but real, pinned, installable
# packages for a deployed container (`docker build` runs in a normal
# environment with network access, unlike the offline build sandbox this
# repository was authored in).
#
# Every module that imports a Layer-B package import-guards it (`try:
# import ... except ImportError:`) — see `docs/OFFLINE_MODE.md` — so the
# SAME source tree runs with only the Layer-A subset installed (labs
# profile, RAFEEQ_MODEL_MODE=stub) or with the full list below (full
# profile, a live deployment).

langsmith>=0.1,<1
