# SDAIA Academy — shared design system (`assets/`)

All Academy sites (Portal, About, Catalog, Graduates, Success Stories) share one design system so they
look and behave like a single platform.

| File | Purpose |
|------|---------|
| `sdaia-ui.css` | Design tokens (brand palette, semantic colours for light + dark themes, type, radius, shadows) and every shared component: header, drawer, hero, KPI tiles, sub-navigation, sections, buttons, cards, chips/tags, forms, notes, progress bars, modal, accordion, footer, back-to-top, tables, print rules. RTL-first with full LTR support via logical properties. |
| `sdaia-ui.js` | Runtime: builds the global header / mobile drawer / footer / back-to-top from one site map, applies the saved language (`sdaia_lang`) and theme (`sdaia_theme`) before first paint, translates every `[data-ar][data-en]` node (plus `data-ar-placeholder`, `data-ar-label`, `data-ar-title`), runs the sub-navigation scroll-spy and the animated counters, and exposes `window.SDAIA = { lang, dark, root, t(ar,en), n(num), icon(name), esc(s), translate(root), setLang(l), setTheme(d), onLang(fn), countUp(el,v), observeCounters(scope) }`. `?lang=en|ar` and `?theme=dark|light` URL parameters override and persist the preference. |
| `sdaia-icons.js` | Inline SVG sprite of the Lucide icons used across the sites (generated by `_build/make-icons.ps1`). Use `<svg class="i"><use href="#i-NAME"/></svg>`. |
| `academy-logo.png` | The official SDAIA Academy logo (used as-is everywhere; never redrawn). |

## Adding a page

```html
<link rel="stylesheet" href="../assets/sdaia-ui.css">
<script src="../assets/sdaia-icons.js"></script>
<script src="../assets/sdaia-ui.js"></script>
…
<header class="sd-header" data-active="catalog" data-sub-ar="الكاتالوج التدريبي" data-sub-en="Learning Catalog"></header>
<main> … <h1 data-ar="عنوان" data-en="Title"></h1> … </main>
<footer class="sd-footer" data-note-ar="…" data-note-en="…"></footer>
```

The header resolves the Academy root from its own script path, so relative depth is automatic.
Page scripts that render data should use `SDAIA.t(ar, en)` for UI labels and subscribe with `SDAIA.onLang(render)`.
Arabic-source data rendered inside the English layout is wrapped in `class="ar"` (and Latin labels inside the
Arabic layout in `class="en"` / `class="ltr"`) so bidirectional text stays correctly aligned.

Numbers use Western digits in both languages (`SDAIA.n()`), matching the rest of the platform.

The single-file Success Stories bundle is regenerated with `SuccessStories/website/build-standalone.ps1`.
