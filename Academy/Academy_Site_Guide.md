## 1. ما هو الموقع؟

موقع أكاديمية سدايا مساحة عمل رقمية موحّدة تعرض أصول الأكاديمية في مكان واحد:

- **التعريف بالأكاديمية:** النبذة والرؤية والرسالة والأهداف والمواءمة الوطنية.
- **الكاتالوج التدريبي:** 37 برنامجًا مترابطًا في 4 مسارات و4 مستويات.
- **بوابة الخريجين:** قاعدة بيانات موثّقة لخريجي الأكاديمية منذ 2021.
- **قصص النجاح:** قصص الخريجين الذين حققوا أثرًا توظيفيًا موثّقًا وفق سياسة معتمدة.
- **الموارد:** الكاتالوج بصيغ Word وExcel وPDF، والعروض، والحقائب التدريبية، وتقارير جولات التحقق.

**خصائص تقنية:**
- **ثابت بالكامل:** HTML وCSS وJS بلا خادم ولا قاعدة بيانات خارجية ولا خطوة بناء، باستثناء ملف القصص المستقل.
- **روابط نسبية:** يمكن نقل المجلد كاملًا أو مشاركته أو رفعه على أي استضافة دون أن ينكسر رابط.
- **ثنائي اللغة:** عربي (الافتراضي) وإنجليزي، مع وضعين فاتح وداكن، ويعمل على الحاسب والجوال.
- **الاعتمادية الخارجية الوحيدة:** خطوط IBM Plex من Google Fonts. بدونها تظهر الصفحات بخط النظام البديل.

**الجمهور:**
- قيادة سدايا والأكاديمية: مؤشرات الأداء والأثر.
- الشركاء والجهات: البرامج والخريجون وقصص النجاح.
- فريق الأكاديمية: الكاتالوج والحقائب والتقارير.
- المرشحون للبرامج: المسارات والمستويات.

## 2. السياق المؤسسي

**أكاديمية سدايا** هي الأكاديمية الوطنية لبناء القدرات في البيانات والذكاء الاصطناعي، وإحدى مبادرات سدايا. تتولى تصميم البرامج والمعسكرات والشهادات المهنية وتنفيذها مع شركاء محليين وعالميين. وتنسجم مع **برنامج تنمية القدرات البشرية** و**رؤية المملكة 2030** و**الاستراتيجية الوطنية للبيانات والذكاء الاصطناعي**. النص الكامل للنبذة والرؤية والرسالة والأهداف الستة في `Academy_Profile.md` وصفحة `about.html`.

**لماذا بُني الموقع؟** كانت أصول الأكاديمية موزّعة على ملفات ومشاريع متفرقة: كاتالوج، وقوائم خريجين، وقصص نجاح، وحقائب مدربين. جمعها الموقع في منظومة واحدة ذات هوية بصرية موحّدة وأرقام قابلة للتحقق، وتُعاد حسابها من البيانات نفسها.

## 6. نموذج البيانات

### 6.1 سجل الخريج: مفاتيح JSON وأعمدة Excel
الورقة الرئيسية في ملف Excel اسمها «قاعدة البيانات».

| JSON | عمود Excel | المعنى |
|---|---|---|
| (الترتيب) | A `#` | رقم السجل، يبدأ من 1 |
| `n` | B الاسم العربي | الاسم كما ورد في المصدر، أو نقل حرفي مُعلَّم بتنويه |
| `en` | C الاسم الإنجليزي | يُحفظ الإملاء الأصلي ويُوحَّد شكل الأحرف فقط |
| `prog` | D البرنامج | نص البرنامج الأصلي، والبرامج المتعددة مفصولة بـ « + » |
| `tr` | E المسار المعياري | `ai`, `ds`, `dmg`, `genai`, `other`, `coop` |
| `co` | F الدفعة/تاريخ التخرج | نص حر يُذكر فيه الشهر والسنة متى توفّرا |
| `emp` / `role` | G / H | جهة العمل والمسمى **الموثّقان** فقط |
| — | I الموقع | غير مستخدم حاليًا |
| `edu` | J التعليم | الجامعة والتخصص والدرجة |
| `lv` | K الطبقة | وسم المصدر أو الجولة، مثل `official`, `nvidia`, `li1026`, `gh1026`, `coop1026` |
| `score` | L درجة الثقة | 0–100 |
| `win` | M النطاق الزمني | ضمن النطاق / حدّي / قبل النطاق / خارج النطاق / غير محدد |
| `cats` | N النتائج | `program`, `cert`, `project`, `job`, `research`, `award` … |
| `links` | O–T | LinkedIn، GitHub، Hugging Face، Kaggle، موقع شخصي، مصادر أخرى |
| `d` | U الوصف/الأدلة | سجل الأدلة، وتُلحق به عند كل تعديل جملة مؤرّخة مثل «[جولة …]» |
| — | V ملاحظات | — |
| `src` | W المصدر | مصدر السجل الأصلي ومصادر الإثراء |
| — | X شارة سدايا | رابط الشارة الرقمية إن وُجدت |
| `alias` | (لا يوجد) | أسماء بديلة مفصولة بـ « · »، تُستخدم في المطابقة |

في ملف Excel أيضًا ورقة «إحصاءات» (الإجماليات والمسارات والدفعات والثقة) وورقة لكل جولة تحقق، منها ورقة «دمج_2026-10-26» لجدول تحويل الأرقام.

### 6.2 المسارات المعيارية وأسبقية التصنيف
يُصنَّف كل سجل في مسار واحد بالترتيب الآتي، **ولا يُعدَّل الترتيب**:
1. ذكر NVIDIA أو إنفيديا أو NCA- أو DLI، أو «أكاديمية الذكاء الاصطناعي التوليدي»، أو الطبقة الرسمية لـ NVIDIA → `genai`.
2. هندسة البيانات أو علوم البيانات (ومنها «معسكر T5 لعلوم البيانات والذكاء الاصطناعي») → `ds`. **علوم البيانات تسبق الذكاء الاصطناعي.**
3. تعلم الآلة، والنماذج اللغوية الكبيرة، والوكلاء، والرؤية الحاسوبية، ومعالجة اللغة الطبيعية، والبرمجة التوليدية، وهندسة الأوامر → `ai`.
4. إدارة البيانات، والحوكمة، والجودة، والبيانات الوصفية → `dmg`.
5. التدريب التعاوني داخل إدارات سدايا → `coop`.
6. ما عدا ذلك → `other`.

وُحّدت 414 صيغة نصية مختلفة لأسماء البرامج، ويبقى النص الأصلي محفوظًا في `prog`.

### 6.3 قصة النجاح (`STORIES` في `data.js`)
الحقول:
- `id`: معرّف بأحرف لاتينية صغيرة وشرطات، فريد.
- `year`: سنة التخرج.
- `quote`: يتكوّن من:
  - `text` و`textEn`: لا يتجاوز أي منهما **100 حرف**.
  - `kind`: `verified` أو `draft`.
  - `original` اختياري: يحفظ النص المعتمد كاملًا إن اختُصر.
- الاسم بلغتين: `name` / `nameEn`.
- `photo`: صورة الخريج.
- `role` / `org` / `orgLogo`: الدور وجهة العمل وشعارها.
- `program` / `period`: البرنامج وفترته.
- `category` / `categories`: الفئة أو الفئات.
- `impact` / `story` / `achievements`: الأثر والقصة والإنجازات.
- `links`: الروابط.
- `provenance`: مصدر التحقق مع إشارة «سجل الأكاديمية #N» إلى سجل الخريج.
- `reviewFlag`: اختياري، يُستخدم للاستثناءات المعتمدة.

### 6.4 الصور والشعارات
- تُحفظ في `SuccessStories/website/assets/` بأسماء لاتينية صغيرة بشرطات، مثل `faisal-alhumayzi.jpeg` و`salam.png`.
- **الصور الفوتوغرافية** تُستخدم كما هي، وحدّها الأقصى 800 بكسل.
- **الصور الرسومية** (اسم مكتوب أو حرف أول أو شعار شخصي) قد يقصّها إطار البطاقة أو يغطيها وسم الفئة. تُوضع في إطار 600×410 بخلفية لونها لون حوافها نفسه، ثم يُفحص شكل البطاقة بلقطة شاشة.
- **الشعارات** تُقصّ حوافها البيضاء. الشعار المكدّس يُستخرج منه الجزء العلوي ليبقى مقروءًا عند ارتفاع 22 بكسل.
- إذا تعارض شعار مُرسل مع السجل (مثل تغيّر اسم الشركة)، يُرجع إلى المصدر الرسمي قبل افتراض أن أحدهما هو الصحيح.

## 7. سياسة قصص النجاح ومعيار المصادر

### 7.1 السياسة المعتمدة (v1.0، 30 أغسطس 2026)
النص الكامل في `SuccessStories/SDAIA_Success_Story_Policy_2026-08-30.md`. يُعتمد الخريج قصة نجاح إذا تحققت **كل** الشروط:
1. **إتمام موثّق:** شهادة، أو سجل رسمي للأكاديمية، أو منشور إتمام شخصي.
2. **نتيجة مؤهِّلة:** توظيف جديد أو تغيير جهة عمل في دور ذي صلة، أو ترقية أو انتقال داخلي ذو صلة، أو تأسيس شركة عاملة، أو إنجاز بحثي أو مفتوح المصدر يتجاوز عتبة الأثر، أو جائزة موثّقة.
3. **التوقيت:** النتيجة تقع **بعد** الإتمام و**خلال 14 شهرًا** منه.
4. **الصلة:** علاقة موضوعية بين مجال البرنامج والنتيجة.
5. **الدليل:** يستوفي معيار المصادر.

**قواعد الحسم المتكررة:**
- **التزامن ليس لحوقًا:** نتيجة في شهر الإتمام نفسه لا تُحتسب، ويُستثنى من ذلك مراكز مسابقات الأكاديمية.
- **التأريخ:** الإتمام المعروف بالسنة فقط يُقرأ على أشده، أي يناير من تلك السنة.
- **ما لا يُعد نتيجة:** شهادة البرنامج نفسه، ومستودع المشروع الختامي بلا اعتراف مستقل، وقيد «متدرب في سدايا» على LinkedIn. كلها مخرجات للبرنامج لا نتائج تالية له.
- **الصلة بالتدريب** أكثر أسباب الرفض شيوعًا. خريج علوم بيانات يعمل في الدعم الفني أو التسويق أو تطوير الأعمال لا تُنسب نتيجته للتدريب.
- **العمل في الجهة المستضيفة:** يُقبل التوظيف في سدايا نفسها إذا ظهر في صفحة خبرة الخريج بتاريخ مستوى الشهر.

**الأحكام المعتمدة لاحقًا (أ. د. ممدوح العنزي):**
- **17 أكتوبر 2026:** الترقية في دور ذي صلة تُعد نتيجة مؤهلة.
- **21 أكتوبر 2026:** برنامج خارجي يتوسّط بين الإتمام والتوظيف (مثل الأكاديمية السعودية الرقمية أو Le Wagon) لا يمنع القصة، ويُذكر في نصها.
- **24 أكتوبر 2026:** رويدا الشهري ليست قصة نجاح، وعلي الغامدي متدرب تعاوني.
- **26 أكتوبر 2026:** قوائم قبول التدريب التعاوني تُضاف منها السجلات المؤكَّدة مع تنويه «الإتمام غير مسجّل». والملف غير المعنون «…4…» هو برنامج شهادات NVIDIA، الدفعة 4.
- **30 أغسطس 2026:** القوائم المعتمدة من الأكاديمية استثناء موروث (`reviewFlag: 'gap'`)، لا مسار اعتماد عادي.

**التصنيف الثلاثي لكل خريج:** مؤهَّل (Validated)، قيد التحقق (Pending Verification)، غير مؤهَّل (Not Qualified).

### 7.2 معيار المصادر والهوية
- **مصادر مقبولة:** LinkedIn (صفحة الخبرة بحساب مسجَّل هي المصدر الوحيد لتواريخ التوظيف بمستوى الشهر)، وGitHub، والمواقع الشخصية، والصفحات المؤسسية، والمنشورات العلمية، والإعلانات الرسمية، وسجلات الأكاديمية الداخلية.
- **ممنوع:** مواقع وسطاء البيانات (مثل ZoomInfo وRocketReach)، كروابط أو كدليل وحيد.
- **عتبة الهوية:** صفتان مستقلتان على الأقل.
  - اسم المستخدم صفة واحدة فقط، حتى لو كان يطابق الاسم الكامل.
  - رابط ملف شخص آخر ليس دليل هوية.
- **المشاريع على GitHub:** يُقبل صاحب النسخة (fork) إذا ملأ سطر «Submitted by» باسمه الكامل، أو ظهر اسمه في ملف التسليم أو اسم العرض، **مع إيداعات من حسابه نفسه**.
  - التحقق من الإيداعات يكون بموجز `commits/<branch>.atom`.
  - `pushed_at` ليس دليل تسليم.
- **مستبعد دائمًا من قاعدة الخريجين:**
  - شهادات مبادرة «سماي» (مليون سعودي للذكاء الاصطناعي).

  - مدرّبو الأكاديمية.
  - برامج جهات أخرى، مثل الأكاديمية السعودية الرقمية وأكاديمية طويق وهاكاثون ALLaM ومسابقة Smartathon.

## 12. مسرد مختصر
- **مؤهَّل / قيد التحقق / غير مؤهَّل:** التصنيف الثلاثي لكل خريج وفق سياسة القصص.
- **نافذة الأربعة عشر شهرًا:** المدة المسموحة بين الإتمام المؤكد والنتيجة المؤهِّلة، شاملة شهر النهاية.
- **إثراء:** إضافة معلومة موثّقة إلى سجل قائم بدل إنشاء سجل مكرر.
- **نقل حرفي (TL):** اسم عربي مشتق من الاسم اللاتيني المنشور، مُعلَّم بتنويه «غير متحقق علنًا».
- **وسم الطبقة (`lv`):** يدل على مصدر السجل وجولته، ويُستخدم لتتبّع الأثر والتراجع عند الحاجة.
- **نسخة الملف الواحد:** موقع قصص النجاح مضمّنًا في ملف HTML واحد قابل للإرسال.
