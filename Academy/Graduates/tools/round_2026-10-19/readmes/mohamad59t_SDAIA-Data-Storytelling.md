# Data Visualization & Storytelling — SDAIA Academy

This repository contains all practical labs and project implementations completed during the **Data Visualization and Storytelling** program at SDAIA Academy.

## Repository Contents
- **Lab 1 & 2:** Exploratory Data Analysis, comparisons, and trend visualizations.
- **Lab 3:** Chart decluttering, visual hierarchy, and Arabic text formatting.
- **Lab 4:** Interactive dashboard elements using Plotly.
- **Lab 5:** SCQA narrative framework, Big Idea definition, and storyboard scenes.
- **Lab 6:** Executive presentation delivery guide and Q&A matrix.

## Tools & Libraries
- Python (Jupyter Notebooks)
- Plotly, Matplotlib, Seaborn, Pandas
