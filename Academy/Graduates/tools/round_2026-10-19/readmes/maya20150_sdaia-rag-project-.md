# 🚀 Advanced RAG & Enterprise AI Infrastructure Pipeline

## 📖 Project Description
An enterprise-grade Retrieval-Augmented Generation (RAG) and intelligent data processing pipeline built as part of the Modern Data Engineering for Advanced AI Systems program (SDAIA Academy). 

This system integrates **FastAPI**, **ChromaDB** for vector storage, and **OpenRouter's OpenAI-compatible API** (supporting advanced models and embeddings) to deliver semantic search, automated skill extraction, and context-aware AI recommendations. The architecture incorporates robust asynchronous event handling patterns and modern data engineering best practices.

---

## 🛠️ Tech Stack & Architecture
* **Core Framework:** Python 3.14+, FastAPI, Uvicorn
* **Vector Database & Storage:** ChromaDB (Persistent Client)
* **LLM & Embeddings Engine:** OpenRouter API (OpenAI-compatible client)
* **Data Processing & Validation:** Pydantic v2, NumPy, PyPDF
* **Concurrency:** Python `asyncio` for event-driven orchestration
